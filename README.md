# Aktapokus Kids English

Free English learning game for children (A1: words, prepositions, question words) with the character Aktapokus.
Runs in the browser and installs as an app (PWA). Works offline after the first load.

- **App:** https://aktapokus.github.io/kids-english/
- **Privacy:** no accounts, no ads, no analytics; data stays on the device unless a child joins a class with a teacher code (parent consent required) - see [privacy.html](privacy.html) and the Turkish data notice [aydinlatma.html](aydinlatma.html)
- **Found a mistake** in a word, sentence or picture? Please open an [issue](https://github.com/aktapokus/kids-english/issues).

Status: early test version. It supports learning and does not replace a teacher.
